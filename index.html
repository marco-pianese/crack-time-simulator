What do these words mean? — entropy, bits, H/s, hash, salt
Entropy, measured in bits

A count of how many passwords yours could have been, as far as the attacker knows. Each extra bit doubles that number, which keeps the figures short instead of twenty digits long.

10 bits = 1,024 possibilities 20 bits = about a million 40 bits = about a trillion 60 bits = about a billion billion
H/s — guesses per second

Hashes per second: how many candidate passwords the attacker tests each second. Ordinary metric prefixes.

1 kH/s = 1 thousand per second k = kilo 1 MH/s = 1 million per second M = mega 1 GH/s = 1 billion per second G = giga 1 TH/s = 1 trillion per second T = tera
Hash

A website doesn't keep your password. It keeps a one-way fingerprint of it — easy to compute forwards, impossible to reverse. One changed letter gives a completely different result.

MD5("cat") = d077f244def8a70e5ea758bd8352fcd8 MD5("cot") = 97223fab7b0d4c64c07e6e004c602302
Salt

A random string the website mixes in before fingerprinting, different for every user. Not secret — it sits beside the hash. It forces an attacker to break each account separately instead of all at once.

MD5("cat") = d077f244def8a70e5ea758bd8352fcd8 MD5("7fK2qR" + "cat") = b0278d78c403b5ad500ad799005ea446
